# Compact R7 figure source data

This directory contains compact, path-sanitized source data for four R7 figure
families: Figure 2 diagnostics, the flow-process schematic, the coverage
trade-off panel, and the frozen case-study window.

`provenance.json` records the immutable R7 delivery-manifest SHA256, the source
data hashes, and hashes of referenced training/evaluation summaries. Candidate-
level distributions, raw hits and already rendered binaries are intentionally
excluded because they are duplicate or nonessential release assets.

The package follows this repository's frozen mixed-temperature protocol. It is
not a fixed-T1 result package and does not approve final manuscript numbering or
layout.
